# 8월 8일 작업 기록 — Visualization 클래스 설계 (시각화 마무리)

`src/visualize/Visualization.ts`(현재 `init`/`render`가 `throw` 스텁)를 완성하기 위한
설계 정리. 코드는 이 문서로 설계를 확정한 뒤 작성한다.

## 클래스 개요

- **3D force graph를 이용한 논문 임베딩 시각화**. 각 논문 = 노드 하나.
- 노드 좌표:
  - **x, y** = `PCA.run(papers)`가 준 제1·제2 주성분 (임베딩을 2D로 투영한 값).
  - **z** = 논문의 **발행 날짜**(`publicationDate`). 시간축.
- force graph 라이브러리를 쓰지만 **좌표는 고정**한다(아래 "좌표 고정" 참고) — 실제로는
  PCA+날짜로 위치가 정해진 3D 산점도에 그래프 상호작용(회전/줌/피킹)을 얹는 형태.

## 데이터 흐름 (VisualizationFlow.run)

다이어그램 규칙: `json 읽기 → PCA → 시각화 일부 작업(init) → 미들웨어 → 시각화 마무리(render)`.
흐름 제어는 `run()` 안에서만 하고 세부 함수가 미들웨어를 직접 호출하지 않는다.

**init이 GraphData를 생성·반환하고**, 미들웨어가 그걸 받아 변형(엣지 추가 등)하고,
render가 인자로 받아 그린다 (2026-08-08 확정). 컨테이너(그릴 DOM)는 GraphData의 필드이며,
뷰가 `setContainer`로 미리 등록하고 init이 생성한 GraphData에 담아 반환한다.

```
VisualizationView:
  this.plugin.visualflow.visual.setContainer(this.contentEl.createDiv())  // 컨테이너 등록
  await this.plugin.visualflow.run()

VisualizationFlow.run():
  papers = File.readPapersByYear(...)          // 저장된 논문 로드
  pca    = this.pca.run(papers)                // ★ PCA는 여기(외부)에서 호출·저장
  graph  = this.visual.init(pca)               // ① init이 GraphData 생성·반환(container 포함, nodes 채움)
  for (mw of this.middlewares) await mw.run(graph)  // ② 미들웨어가 nodes/links 변형(엣지 추가 등)
  this.visual.render(graph)                    // ③ graph.container에 실제 렌더
```

- **★ PCA 호출 위치 (2026-08-08 확정)**: PCA는 `init` 내부에서 부르지 않는다. `run()`이
  외부에서 `this.pca.run(papers)`를 호출해 `PCAResult`를 얻어 보관하고, 그 값을 `init`에
  **인자로만** 넘긴다. `Visualization.init`은 PCA를 몰라도 되며(PCA 의존 없음), 전달받은
  좌표를 그래프 데이터로 변환만 한다.
- **컨테이너 주입**: 뷰가 `visual.setContainer(div)`로 미리 등록 → init이 새 GraphData에
  `graph.container`로 담아 반환 → render가 사용. (run/render 시그니처에 container 안 붙음)

핵심: **init이 만든 하나의 GraphData가 미들웨어(변형)→render(그림)를 관통한다.**
미들웨어는 이 GraphData의 `nodes`/`links`를 제자리에서 수정한다(엣지 추가 등).

## 함수 설계

### `init(pca: PCAResult): GraphData` — 시각화 일부 작업

**PCA를 직접 호출하지 않는다.** 외부(`run()`)에서 계산·저장된 `PCAResult`를 인자로
받아 **새 GraphData를 만들어 채우고 반환**한다. 화면에 그리지는 않는다. 하는 일:

1. `new GraphData()` 생성. `graph.container = this.container`(setContainer로 받아둔 DOM)를 담는다.
2. **노드 생성**: `pca.points`의 각 점 → 노드. `id = sourceId`, `paper` 참조 보관.
3. **z(시간축) 매핑**: `paper.publicationDate`(ISO "YYYY-MM-DD") → `Date.parse`로 timestamp
   (일 단위)로 바꾸고, 전체 범위(min~max)를 z 좌표 범위로 정규화.
4. **x, y 펼치기(spreading)**: 표준화(z-score) × 배율로 뭉친 좌표를 넓게 편다(아래 "펼치기").
5. **좌표 고정**: 각 노드에 `fx/fy/fz`를 세팅해 force 시뮬레이션이 위치를 흔들지 않게 함.
6. `graph.nodes`와 z축 눈금용 `timeRange`를 채운다. **`graph.links`는 비워 둔다**(노드만 —
   엣지는 미들웨어가 추가). 완성된 `graph`를 `this.graph`에도 저장하고 **반환**한다.

- init은 **데이터 채우기**만 — DOM/WebGL 객체 생성이나 렌더링은 하지 않는다(미들웨어가
  그 사이에서 데이터를 만질 수 있어야 하므로).

### `render(graph: GraphData): void` — 시각화 마무리 (진짜 그리기)

미들웨어까지 거친 최종 GraphData를 받아 **`graph.container`에** 실제로 그린다. 하는 일:

1. `graph.container`에 3d-force-graph 인스턴스를 붙이고 `graph.nodes`(+미들웨어가 넣었으면
   `graph.links`)를 넣어 노드 위치를 `fx/fy/fz`로 고정.
2. 노드 렌더 속성 반영: 크기 = 인용수 기반, 색 = 고정 단색, 라벨 등(미들웨어가 넣은 값 포함).
3. **z축(시간축) 그리기**: 시간 방향을 보여주는 축 가이드(선 + 연도 눈금/라벨)를 그린다
   (아래 "z축 그리기").
4. **옵션 반영**: `graph.options.fullscreen`이 켜져 있으면 컨테이너를 전체 화면으로 만든다.
5. **이벤트 연결**: `graph.events.nodeHover`/`nodeClick`의 핸들러들을 3d-force-graph의
   `onNodeHover`/`onNodeClick`에 연결(등록된 핸들러 전부 호출).
6. 카메라·상호작용 초기화.

## 인자/반환값 (미들웨어를 사이에 끼우기 위한 계약)

| 함수 | 인자 | 반환 | 이유 |
|---|---|---|---|
| `setContainer` | `el: HTMLElement` | `void` | 뷰가 그릴 DOM을 미리 등록 |
| `init` | `pca: PCAResult` | `GraphData` | 미들웨어가 만질 GraphData를 생성해 밖으로 내보냄 |
| (미들웨어) | `graph: GraphData` | `void`(제자리 변형) | init이 만든 GraphData의 nodes/links를 수정 |
| `render` | `graph: GraphData` | `void` | 미들웨어가 수정한 최종본을 `graph.container`에 그림 |

- 미들웨어는 `Middleware.type === 'visual'`, `run(context)`의 `context`가 `GraphData`다
  (`src/common/Middleware.ts`의 `context: unknown`을 여기서 GraphData로 구체화).
- 미들웨어 예시: 색 입히기(주제별/연도별), 특정 노드 강조, 클러스터 라벨, 추가 축/격자,
  펼치기 강도 조정 등 — **init과 render를 건드리지 않고** 끼워 넣는다.

## z축(시간축) 처리

- **매핑**: `publicationDate` → `Date.parse`로 timestamp(일 단위). 날짜 없음/파싱 실패
  시 잠정으로 z 최소값에 배치.
- **정규화**: 날짜 범위(min~max)를 z 좌표 범위(예: 0~L)로 선형 매핑.
- **축 그리기(render)**: z 방향을 따라 축 선을 긋고 연도 눈금·라벨을 배치해, 사용자가
  "안쪽으로 갈수록 오래된/최신 논문"임을 알 수 있게 한다.

## x, y 펼치기(spreading)

임베딩(그리고 그 PCA 투영)이 서로 가깝게 뭉쳐 있어 그대로 그리면 점들이 겹친다. init에서
**표준화(z-score) × 배율**로 편다(확정): x,y를 각각 평균 0/표준편차 1로 만든 뒤 배율을
곱한다. 뭉친 본집단이 고르게 퍼지고 이상치는 멀리 간다. 배율은 상수로 두되 미들웨어로
조정 가능하게 한다.

## GraphData 구조 (제안)

현재 `GraphData`는 빈 클래스다. 아래처럼 채우는 것을 제안(구현 시 확정):

```ts
interface GraphNode {
  id: string;            // sourceId
  fx: number; fy: number; fz: number;  // 고정 좌표 (x,y=PCA 펼침, z=날짜)
  paper: Paper;          // 크기(인용수)·라벨·색 계산용 원본
  size?: number; color?: string; label?: string; // 미들웨어/render가 채우는 표시 속성
}
interface GraphLink { source: string; target: string; }  // 노드 id(sourceId) 기준
interface GraphViewOptions { fullscreen: boolean; }       // 렌더 옵션 (전체 화면 등)
interface GraphEvents {                                   // 이벤트 핸들러(미들웨어가 push)
  nodeHover: ((node: GraphNode | null) => void)[];
  nodeClick: ((node: GraphNode) => void)[];
}
class GraphData {
  container?: HTMLElement;   // 그래프를 그릴 DOM (VisualizationView가 setContainer로 세팅)
  nodes: GraphNode[] = [];   // init이 채움
  links: GraphLink[] = [];   // init은 비워 둠 — 미들웨어가 엣지 추가
  timeRange?: { min: number; max: number };  // z축 눈금 그릴 때 사용
  options: GraphViewOptions = { fullscreen: false };      // 전체 화면 등 — render가 반영
  events: GraphEvents = { nodeHover: [], nodeClick: [] };  // hover/click — render가 연결
}
```

(실제 구현: `src/visualize/GraphData.ts` — 위와 동일하게 정의됨.)

## 상호작용/표시 옵션 (전체 화면·이벤트) — 2026-08-08 추가

미들웨어는 init과 render 사이에 돌아서 **아직 씬(3d-force-graph 인스턴스)이 없다.** 그래서
씬을 직접 만지지 못하고, 하고 싶은 걸 GraphData에 **의도로 남기면 render가 실현**한다.
이를 위해 GraphData에 두 가지를 추가했다:

- **`options`(`GraphViewOptions`)** — 렌더 옵션. 현재 `fullscreen: boolean`(전체 화면으로
  띄울지). render가 이 값을 보고 컨테이너를 전체 화면으로 만든다(Fullscreen API 또는 전체
  뷰포트 CSS). 뷰나 미들웨어가 `graph.options.fullscreen = true`로 켠다. 옵션은 확장 가능.
- **`events`(`GraphEvents`)** — 노드 이벤트 핸들러 배열. 미들웨어가
  `graph.events.nodeHover.push(fn)` / `nodeClick.push(fn)`으로 핸들러를 더하고, render가
  3d-force-graph의 `onNodeHover`/`onNodeClick`에 연결해 등록된 핸들러를 모두 호출한다.
  단일 콜백이 아니라 **배열**이라 여러 미들웨어가 각자 반응을 붙일 수 있다.
  - 예) 어떤 미들웨어: `graph.events.nodeHover.push(node => showTooltip(node?.paper))`
  - 필요 시 `linkHover`, `backgroundClick` 등 이벤트 종류를 `GraphEvents`에 추가.

이로써 미들웨어가 **전체 화면 표시**와 **hover/click 반응**을 얹을 수 있다. (씬에 축·격자
같은 3D 오브젝트를 직접 추가하는 것은 별도 — 필요하면 "렌더 훅" 방식을 추후 도입.)

## 확정 사항 (2026-08-08)

1. **라이브러리**: `3d-force-graph`(three 기반) 사용. npm으로 설치해 esbuild로 번들.
2. **링크**: **노드만** 그린다(인용 엣지 없음). 필요 시 나중에 미들웨어/후속으로 추가.
3. **z 매핑 단위**: **날짜(일 단위), 실시간 비례** (2026-08-08 변경 — 처음엔 고정 길이로
   정규화했으나, 수집 기간이 길수록 축이 실제로 길어지길 원해 비례 방식으로 전환).
   `fz = (t - tMin) / MS_PER_DAY * Z_PER_DAY` — tMin(가장 오래된 논문) 기준 상대 시간 ×
   하루당 거리(`Z_PER_DAY`, 튜닝값). z축 길이도 이 값으로 계산해 기간에 비례. (날짜 없음/
   파싱 실패 시 z 최소값에 배치 — 잠정.)
4. **펼치기**: **표준화(z-score) × 배율**. x,y를 각각 평균 0/표준편차 1로 만든 뒤 배율을
   곱한다. 배율은 상수(추후 미들웨어로 조정 가능).
5. **노드 시각 속성**: 크기 = **인용수 기반**(citationCount, 로그 스케일 권장), 색 = **고정
   단색**. (주제별/연도별 색은 나중에 미들웨어로.)
6. **render 컨테이너**: **GraphData의 필드로 전달**. `VisualizationView`가 그래프용 div를
   만들어 `visual.setContainer(div)`로 등록 → `init`이 생성한 GraphData의 `graph.container`에
   담아 반환 → `render`가 `graph.container`에 그림.
7. **엣지(links)**: init은 만들지 않지만, 미들웨어가 추가할 수 있도록 `GraphData.links` 필드는
   둔다(현재 GraphData에 `GraphLink[]`로 존재). render는 `graph.links`가 있으면 함께 그린다.

### 남은 잠정/후속

- 날짜 없는 논문의 z 처리(현재 "최소값에 배치" 잠정) — 실데이터 보고 확정.
- 펼치기 배율·노드 크기 스케일의 구체 상수값 — 실제로 그려보며 튜닝.

## 진행한 작업 (구현)

- `src/visualize/GraphData.ts`: `GraphNode`/`GraphLink`/`GraphViewOptions`/`GraphEvents` +
  `GraphData`(container/nodes/links/timeRange/options/events).
- `src/visualize/Visualization.ts`: `setContainer`/`init`/`render` 구현.
  - `init(pca)`: GraphData 생성·반환. x,y는 z-score×배율로 펼치고, z는 publicationDate
    timestamp를 정규화. 좌표를 fx/fy/fz로 고정, 크기=인용수 로그 스케일, 색=단색.
  - `render(graph)`: `graph.container`에 3d-force-graph 인스턴스 생성, nodes/links 주입,
    hover/click 이벤트 연결, z축 선+연도 라벨(three) 그림, `options.fullscreen` 반영.
- 의존성 설치: `3d-force-graph`, `three`, `@types/three`.
- **후속 완료**: `VisualizationFlow.run()` 구현(008.md)과 `VisualizationView` 배선
  (onOpen에서 setContainer + run 버튼)까지 마침.
- **미검증**: 사용자 요청으로 빌드는 아직 안 함. esbuild 번들(3d-force-graph/three)과
